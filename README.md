# BREF RESUME DE LA SESSION DU 28/10/2026

| ACTIVITES REALISES | COMMANDES UTILISEES | DESCRIPTION |
|---------------------|----------------------|--------------|
Installation / activation de npm | - | npm est le gestionnaire de package par defaut de node.JS. il permet de d'installer des packages externes dans node.JS.
Initialisation de npm dans le dossier | npm init -y | Génère un fichier package.json. Elle permet également d'actualiser le fichier package.json
Installation de node-emoji | npm install node-emoji | Installe le package node-emoji dans l'installation node.JS. Ce package permet d'intégrer des emojis dans les chaines de caractères.
Importation du module `readline` | `require("node:readline")` | `require`est le chargeur de module de base de Node.JS. Un module est un fichier .js. `require` recoit comme valeur le chemin d'accès du module, ou seulement le nom du module s'il se trouve dans le repertoire courant.|
Construction d'un gestionnaire d'évènement | `require("node:readline"), readline.createInterface()` | Permettent d'interagir avec l'utilisateur en lui donnant l'opportunité d'entrer une valeur.
