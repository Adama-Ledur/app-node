Installation / activation de npm | - | npm est le gestionnaire de package par defaut de node.JS. il permet de d'installer des packages externes dans node.JS.
Initialisation de npm dans le dossier | npm init -y | Génère un fichier package.json. Elle permet également d'actualiser le fichier package.json
Installation de node-emoji | npm install node-emoji | Installe le package node-emoji dans l'installation node.JS. Ce package permet d'intégrer des emojis dans les chaines de caractères.
Importation du module `readline` | `require("node:readline")` | `require`est le chargeur de module de base de Node.JS. Un module est un fichier .js. `require` recoit comme valeur le chemin d'accès du module, ou seulement le nom du module s'il se trouve dans le repertoire courant. Ainsi la commande `require("node:readline")` va chercher le module `readline` pour le rendre accessible dans le fichier .js en cours d'utilisation|
Un gestionnaire d'évènements |`readline`| `readline`est un module qui permet d'entrer des informations externes provenant de l'utilisateur ligne par ligne au moment voulu. |
Construction d'un gestionnaire d'évènement | `readline.createInterface()` | Le readline comporte plusieurs modules qui permettent d'interagire avec l'utilisateur. Ces interactions passent par la création d'un gestionnaire d'évènement `readline.createInterface()`. Cette fonction prend deux paramètres que sont `process.stdin`et `process.stout, qui permettent de lire respectivement l'entrée et la sortie . |
Introduire une réquête à l'utilisateur | `rl.question()`| la `rl.question()` est la méthode qui permet de poser des questions à l'utilisateur et de lire la reponse (`output`). Elle prend deux arguments : Le premier est la question et le second est une funtion `callback` qui va prendre la reponse de l'utilisateur et l'afficher sur le terminal. e.g. `rl.question('What is your age? ', (age) => {console.log('Your age is: ' + age);});`|
Introduire une réquête à l'utilisateur | `rl.setprompt()`, `rl.prompt()` et `rl.on()` | `rl.setprompt()` est une autre méthode pour demander à l'utilisateur d'entrer une valeur. Toutefois, elle a besoin de rl.prompt pour récuperer cette reponse. Contrairement à `question()`, les valeurs obtenues grâce à `rl.setprompt()`, `rl.prompt` et `rl.on()` sont réutilisables. `rl.setprompt()` prend un seul argument correspondant à la question tandis que `rl.prompt()` n'en prend aucun. Cette dernière méthode permet juste de signaler à l'utilisateur qu'il doit entrer une valeur à l'aide d'un prompt. `rl.on()` permet de lire la valeur entrée par l'utilisateur et de l'afficher sur la console. Cette méthode prend deux arguments: `line` qui permet au programme de réagir au clic sur la touche `entrer`, et une fonction callback qui correspond à l'action à réaliser suite à ce stimilus |
Intérruption de la réquête | `rl.close()` | Afin d'empêcher le programme de poser la question incéssament la même question, on utilise la méthode `rl.close()`qui permet d'arrêter la réquête. Cette méthode s'utilise à l'intérieur de `rl.question`. |
